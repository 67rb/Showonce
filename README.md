# SHOW ONCE

SHOW ONCE is a mobile-first web app that turns a short video of a hands-on
object skill into a step-by-step lesson, checked photo by photo as you go. This
repository is the **design scaffold only** — it contains the complete design
system, every page of the final product, and the navigation between them, but
no working tools yet. Photos are never stored: "checks photos, keeps nothing."

## Run it locally

```bash
npm install
npm run dev
```

Open the landing page at http://localhost:3000, and the internal design-review
index at http://localhost:3000/design. All fixture content is design-only and
is replaced when the tools are built.
